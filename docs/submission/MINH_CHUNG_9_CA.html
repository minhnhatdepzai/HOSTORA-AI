NHÓM 04 · BỔ SUNG

Hộp thư AI và quản trị viên

3/3 đạt
S01ĐẠT

Câu hỏi ngoài HOSTORA được chuyển người thật

Thao tác
Khách hỏi thời tiết và nhập số điện thoại thử nghiệm.
Cần thấy
Lưu hội thoại đã ẩn số; trạng thái chờ admin; lịch gửi email chỉ tạo một lần.
Kết quả
Web và APK hiện “Đã chuyển quản trị viên”; database không còn số điện thoại gốc; SMTP mock nhận cảnh báo kèm link admin.
S02ĐẠT

Người lạ không đọc được hội thoại khách ẩn danh

Thao tác
Gọi API hội thoại bằng token sai, sau đó bằng token đúng.
Cần thấy
Token sai không làm lộ việc hội thoại có tồn tại; server chỉ lưu hash token.
Kết quả
Token sai nhận 404; token đúng đọc được thread đã ẩn dữ liệu. Admin vẫn cần phiên ký hợp lệ và cùng origin.
KIỂM TRA QUYỀN TRUY CẬPToken sai → 404Không trả nội dung, tên khách, trạng thái hoặc dấu hiệu giúp dò mã hội thoại.
S03ĐẠT

Admin trả lời, khách tự nhận lại trên web và APK

Thao tác
Admin mở /admin/support, đọc timeline, gửi phản hồi; khách không tải lại thủ công.
Cần thấy
Web/app tự kiểm tra, giữ hội thoại và phân biệt rõ AI với quản trị viên.
Kết quả
Phản hồi xuất hiện với nhãn “Quản trị viên HOSTORA”; trạng thái đổi thành “Đã phản hồi”. APK mới cài đè vẫn giữ thread cũ.
